ÉTAPE 1: PRÉREQUIS SYSTÈME
==================================================

1.1 Vérifier PHP
Commande: php --version
Résultat attendu: PHP 8.2.0 ou supérieur
Si erreur: Installer PHP depuis https://www.php.net/downloads.php

1.2 Vérifier Node.js
Commande: node --version
Résultat attendu: v18.0.0 ou supérieur
Si erreur: Installer Node.js depuis https://nodejs.org/

1.3 Vérifier Flutter
Commande: flutter --version
Résultat attendu: Flutter 3.11.0 ou supérieur
Si erreur: Installer Flutter depuis https://flutter.dev/docs/get-started/install/windows

1.4 Vérifier Docker
Commande: docker --version
Résultat attendu: Docker 20.10.0 ou supérieur
Si erreur: Installer Docker Desktop depuis https://www.docker.com/products/docker-desktop/

ÉTAPE 3: TEST BACKEND API
==================================================

3.1 Test de santé API
Commande: Invoke-WebRequest -Uri "http://localhost:8000/api/health"
Résultat attendu: StatusCode 200 OK

3.2 Test authentification admin
Commande: $body = @{email="admin@servicy.tn";password="admin123"} | ConvertTo-Json
Commande: $response = Invoke-WebRequest -Uri "http://localhost:8000/api/login" -Method POST -ContentType "application/json" -Body $body
Commande: $data = $response.Content | ConvertFrom-Json
Commande: $token = $data.token
Résultat attendu: Token JWT reçu

3.3 Test endpoint services
Commande: $headers = @{Authorization = "Bearer $token"}
Commande: Invoke-WebRequest -Uri "http://localhost:8000/api/services" -Headers $headers
Résultat attendu: Liste des services retournée

3.4 Test création rendez-vous
Commande: $appointment = @{provider_id=1; service_id=1; scheduled_at=(Get-Date).AddDays(1).ToString("yyyy-MM-ddTHH:mm:ss"); description="Test appointment"; budget=100.0; address="Test Address"; latitude=36.8065; longitude=10.1815} | ConvertTo-Json
Commande: Invoke-WebRequest -Uri "http://localhost:8000/api/appointments" -Method POST -Headers $headers -ContentType "application/json" -Body $appointment
Résultat attendu: Rendez-vous créé avec succès

ÉTAPE 10: TESTS DE SÉCURITÉ
==================================================

10.1 Test authentification invalide
Commande: $body = @{email="admin@servicy.tn";password="wrongpassword"} | ConvertTo-Json
Commande: try { Invoke-WebRequest -Uri "http://localhost:8000/api/login" -Method POST -ContentType "application/json" -Body $body } catch { Write-Host "Sécurité OK: Rejeté" }
Résultat attendu: "Sécurité OK: Rejeté"

10.2 Test injection SQL
Commande: $malicious = @{description="'; DROP TABLE users; --"} | ConvertTo-Json

DÉPANNAGE RAPIDE
==================================================

Commande: rm -rf node_modules
Commande: npm install

Commande: cd backend
Commande: php bin/console doctrine:database:create
Commande: php bin/console doctrine:migrations:migrate
